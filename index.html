Dúvidas frequentes

Minha foto é enviada para algum servidor?

Não. Todo o processamento é feito no seu próprio navegador com HTML5 Canvas. A imagem nunca é enviada para a internet e nada fica salvo em nenhum servidor.

Qual o tamanho da imagem gerada?

1080×1080 pixels em PNG, resolução recomendada para foto de perfil em qualquer rede social.

Funciona no celular?

Sim. Você pode escolher uma foto da galeria, arrastar para posicionar e usar dois dedos para dar zoom.

Posso usar em material impresso?

A imagem é gerada em 1080×1080, ideal para redes sociais. Para impressos grandes, prefira uma arte feita em alta resolução.

Este site é oficial?

Não. É uma ferramenta independente feita por apoiadores para uso pessoal em redes sociais, sem vínculo com candidatos, partidos, comitês ou órgãos oficiais.
